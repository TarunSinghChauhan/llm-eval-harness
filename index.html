LLM Evaluation Harness: Scoring Playground

Browser demo of the scoring and regression-check logic from llm-eval-harness
What this is: a demo of the harness's scoring math (ROUGE-L, exact match, bootstrap confidence intervals, regression check). It runs entirely in your browser; nothing is uploaded and no model is called.
What this is not: a benchmark of real models. The pre-filled sample is illustrative. BERTScore, the LLM-as-judge ensemble and the red-team suite need model APIs and are not run here.

1. Data (one JSON object per line)

Fields: reference, baseline (output of the current system), candidate (output of the new system). Edit the sample or paste your own.

How the numbers are computed

ROUGE-L F1: longest common subsequence between candidate and reference after lowercasing and splitting into word tokens; F1 of the LCS precision and recall.
Exact match: 1 if candidate equals reference after lowercasing and removing punctuation, otherwise 0.
95% confidence interval: percentile bootstrap, 1,000 resamples, fixed seed 42, so the same input always gives the same interval.
Regression alert: flagged when the candidate mean minus the baseline mean is below minus the threshold (absolute difference, default 0.02).
